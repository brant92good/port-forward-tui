# Screenshot fonts

Fira Code 6.2, Regular and Bold, from the
[Fira Code project](https://github.com/tonsky/FiraCode/releases/tag/6.2).
The WOFF2 files were obtained from cdnjs's `firacode/6.2.0/woff2/` distribution.
Copyright belongs to The Fira Code Project Authors; see [LICENSE](LICENSE).

The screenshot script embeds these files and their license into each exported
SVG. README images therefore do not depend on network font requests, which
browsers block when SVG is used as an image.
