# Ports 0.10.0-beta.1

This is an explicit beta channel for saved SSH SOCKS proxies, alongside fixed
local forwards. Check the [exact release](https://github.com/brant92good/port-forward-tui/releases/tag/v0.10.0-beta.1)
and its workflow results before installing. An available download alone does not
establish that every post-publication HTTPS test passed.

The beta uses protocol 2 and a separate data/controller namespace. It does not
share a controller with stable Ports or the historical Python app. Stable local
favorites retain their original schema; SOCKS-capable data uses schema 2. Do not
point stable Ports at beta data. Explicit metadata import is separate from
installation and must not copy active endpoints, controller locks or automatic
opening preferences.

The default installer remains pinned to **0.9.1**. Beta installs use
`ports-beta`/`ports-beta.exe`, a distinct directory and ownership marker, and
never modify PATH. Stable programs and settings remain in place. Exact beta
commands, qualification gates and rollback are documented in
[Versioning and release channels](https://github.com/brant92good/port-forward-tui/blob/v0.10.0-beta.1/docs/versioning.md).

SOCKS uses OpenSSH's loopback `-D` listener with `-N` (no remote command). Configure
a proxy-aware client to use it; this is TCP forwarding, not a device-wide VPN.
Starting a proxy does not start a web server, open a browser or automatically
proxy other applications. ON means an owned local SSH listener, not proof that
every remote destination is available. macOS and this feature remain beta.

The release record attached to these immutable assets binds source commit,
version/channel, all five source/package qualification rows and archive hashes.
Post-publication HTTPS receipts remain separate because those checks necessarily
run after the record is frozen. Independent review and the owner's install
receipt must precede a personal beta deployment. No tag or published asset may
be replaced after a failure; the correction receives a new beta version.
